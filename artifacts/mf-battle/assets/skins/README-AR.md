# صور السكنات (اختياري)

تكدر تبدّل رسمة أي سكن بصورة من عندك:

1. حط الصورة بهذا المجلد (`assets/skins`). الأفضل تكون مربعة (مثلاً 512×512) وبصيغة PNG أو WEBP أو JPG.
2. افتح `images.json` واكتب اسم السكن واسم الصورة، مثل:

```json
{
  "joyboy": "joyboy.png",
  "roger": "roger.webp",
  "zoro": "zoro.jpg"
}
```

3. ارفع المجلد على Cloudflare من جديد.

أسماء السكنات: `fly`، `mf`، `joyboy`، `roger`، `kaido`، `zoro`، `sanji`، `imu`، `whitebeard`، `usopp`.

الصورة تنقص دائرية تلقائياً، باللعبة وبالمتجر. أي سكن ما إله صورة يبقى على الرسمة.
